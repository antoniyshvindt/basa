# Шаблон: бюджетный разбор (регион / группа / все субъекты)

# [Формула-вывод: «Доходы падают, расходы растут» / «Устойчивость за счёт Москвы» …]
*Период: [..] к тому же периоду; источник: Казначейство / Минфин / ФНС, дата.*

1. **Доходы.** Всего [%] (реально [%]); собственные [%]; безвозмездные [%]. Падение доходов в [N] регионах.
   Разложение прироста: налог на прибыль […], НДФЛ […], имущество […], прочие […], трансферты […].
   Регионы по доминирующему источнику изменения: […].
2. **Налог на прибыль.** Где упал/вырос и почему (цены, экспорт, КГН, перерегистрация, лаг нефтегаза,
   федеральное изъятие прироста ставки).
3. **Трансферты.** По видам (выравнивание / сбалансированность / субсидии / субвенции / иные МБТ);
   доля непрозрачных; **тест на адресность**: таблица «выпавшие собственные доходы vs дополнительная
   помощь» по наиболее пострадавшим; кому дали без потерь; политический календарь.
4. **Расходы.** Всего [%] против инфляции [%]; по статьям: образование, здравоохранение (с ТФОМС),
   соцполитика (пособия, выплаты контрактникам/семьям), ЖКХ, нацэкономика (дороги, транспорт).
   Что реально в приоритете, на чём экономят. Москва отдельно.
5. **Дефицит.** Число регионов; худшие в % доходов; причина (падение доходов vs неэффективная политика);
   прогноз к декабрю.
6. **Долг.** Объём, нагрузка к собственным доходам, структура (бюджетные кредиты / банки / облигации),
   обслуживание, списания и реструктуризации, кассовые разрывы.
7. **Вывод.** Устойчиво/неустойчиво по четырём элементам; кто в зоне риска; от каких федеральных решений
   зависит; что последует для населения (соцрасходы, выплаты, инфраструктура). Формула-итог.
