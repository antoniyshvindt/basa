# Отраслевой сегмент «Химическая промышленность» · домен «Наука и инновации» (демонстрационный макет)

Пример: **титаномагниевый катализатор Циглера–Натта для производства полипропилена** — каталитическая система
«ТМК (TiCl₄/MgCl₂ + внутренний донор) + триэтилалюминий + внешний донор-силан».

Почему он: самый массовый промышленный катализатор полиолефинов; в России почти полностью импортируется, а цепочка
«Катализаторы химической промышленности и металлоорганические соединения» входит в ФП «Развитие производства химической
продукции» НП «Новые материалы и химия» (дорожная карта подписана — презентация Минпромторга, документ пользователя).
Непростой: морфология частицы, доноры, пирофорный сокатализатор, совместимость с технологиями лицензиаров ПП.

## Запуск
```bash
node tools/build-anatomy.mjs   # изометрическая схема производства → assets/anatomy/plant.svg
node tools/build-data.mjs      # данные → data/*.json (с проверкой ссылок)
node tools/build-single.mjs    # один офлайн-файл → dist/chem-atlas-zn.html
python3 -m http.server 8766    # открыть http://localhost:8766/
```

## Разделы
Анатомия (12 подсистем S01–S12, 7 стадий цикла, «лупа» частицы) · НПТЛ и ВНТ (ВНТ № 24, 23, 25) · Технологии T01–T13 ·
НИОКТР (ЕГИСУ: 15 карточек, 5 РИД, лоты РНФ 2023–2026) · Компетенции (10 организаций) · Патенты (РИД; зарубежные — ограничение) ·
Рынок и санкции (eCFR Supplement No. 4) · Ввоз по 26 компонентам · УГТ (аналитическая адаптация, ТУ и регламенты) ·
Стандарты и среды (ТР ЕАЭС 041/2017 и др.) · Поддержка · Граф знаний · Дефициты и проект развития · Источники.

## Принципы
Данные из первоисточников (ЕГИСУ, eCFR, Crossref, rscf.ru, презентация Минпромторга) отделены от аналитики макета;
сведения СМИ помечены; непроверенное — статусом «проверить»/«не проверено». Подробности — `research/`.
